## 2026-09-13, Day 1

What does Vite+ do?:

- Vite+ aims to fix the fragmentation for web apps, different teams can end up using different tooling stack.
- Provides lots of pre-bundled tooling like Vitest for testing, Oxlint and Oxfmt for linting and format.
- A lot of the tooling is written in Rust for fast performance, but also provides easily extensibility due to leveraging NAPI-RS to bridge Rust and JS.
